# 内置主图公式

## 使用与范围

行情图表 `ChartWidget` 和 A 股日线图 `DailyChart` 默认开启独立的「主图公式 / Main formula」。按钮以 `aria-pressed` 表示状态，可随时关闭或重新开启；开关不重建图表，也不清除其它原生指标或自定义 Pine。

组件内关闭状态在证券、周期和历史数据变化时保留。异步初始化读取最新开关状态，行情加载完成不会重新开启已关闭的公式。状态不保存到工作区，重新挂载组件后恢复默认开启。证券和历史变化通过现有 adapter 更新行情并重算，不改变行情源、交易逻辑或量化策略。

`createChartAdapter` 第三个可选参数为 `onMainFormulaChange(enabled)`。adapter 监听 Vela 公开的 `indicator:removed` 和 `indicator:visibility` 事件；从图例移除或隐藏主图公式时清空句柄并通知关闭，隐藏按移除处理，按钮再次开启会创建新指标。其它指标的事件不改变主图开关，销毁时解除订阅且不再通知。

两处图表的回调同步更新 `mainFormulaRef` 和 React 状态，按钮及公式说明立即反映图例操作。回调受 `cancelled` 防护，卸载或被替换图表的晚到通知不改变当前状态；日线数据清空后恢复时仍沿用同步后的开关值。图例关闭后行情异步完成不会复活公式，可通过主图按钮重新开启，不影响 Pine 或其它指标。

公式计算使用当前图表周期的 K 线，日线图固定为 `1D`。分钟线的 8.5% 标记表示相邻分钟 K 线涨幅，不是日涨幅。双 KDJ 用于压力/支撑计算，不另绘 KDJ 副图。

## 均线与颜色

均线使用收盘价的完整窗口简单平均；未达到对应根数时不输出该均线。

| 周期（K 线根数） | 颜色 |
| --- | --- |
| 5 | `#FFFFFF` |
| 10 | `#00FFFF` |
| 15 | `#FFFF00` |
| 30 | `#FF00FF` |
| 50 | `#FF0000` |
| 100 | `#FFCC66` |
| 200 | `#FF6600` |

颜色按字面 RGB 解析，不交换颜色通道。七条均线为实线，压力为黄色 `#FFFF00` 点线，支撑为绿色 `#00FF00` 点线。

## 双 KDJ 与事件

短周期 `Z=5`，长周期 `Y=55`。每根 K 线仅使用截至当前根的历史；窗口不足时使用已有历史。

```text
RSV = (C - LLV(L, N)) / (HHV(H, N) - LLV(L, N)) * 100
K = (RSV + 2 * K_prev) / 3
D = (K + 2 * D_prev) / 3
J = 3 * K - 2 * D
```

首次有效 RSV 初始化 K，首次有效 K 初始化 D。零振幅时该根 RSV/K/D/J 不输出，内部保留上一有效 K/D 平滑状态供后续有效根继续递推。

`CROSS(A,B)` 仅在当前 `A>B` 且前根 `A<=B` 时成立；当前或前根任一值缺失都不触发。`CROSS(J55,J5)` 取事件所在根最高价作为压力，`CROSS(J5,J55)` 取事件所在根最低价作为支撑。各自保持最近一次事件价格，首事件前不输出；不使用未来数据。

## 黄色实体

```text
(C - C_prev) / C_prev * 100 >= 8.5
```

前收盘缺失或为零时不触发。满足条件时用黄色实心矩形覆盖当前根 O 到 C 的实体，保留原影线。绘制层使用 Vela 公开的坐标与 bar 间距接口，宽度为 `max(1 / dpr, floor(bodySpacing * 0.7))`，零高度实体保留至少 `1 / dpr`；随图表缩放适配，不复刻通达信固定像素宽度 2。

缺失、非有限坐标及可视范围外的实体不绘制。关闭公式移除系列与实体图层，销毁图表释放资源。

## 历史边界

少于 200 根 K 线时，两处 UI 均显示长周期均线历史不足提示；199 根不输出 MA200，第 200 根首次输出。满足完整窗口的短均线仍正常输出。关闭公式后隐藏公式说明。

不自动补取或伪造行情；压力/支撑仅来自当前传入窗口内的事件，窗口外的最近事件不会恢复。历史范围或证券变化后从当前数据重新计算，因此截断窗口可能改变 KDJ 初值及压力/支撑。

## 验证与限制

纯计算测试覆盖初值、零振幅、相等交叉边界、事件保持、MA199/200、8.5% 门槛、标的隔离和前缀无未来数据。绘制测试覆盖系列颜色/点线、坐标、缺失不画及清理；真实已安装 Vela 生命周期测试覆盖重算和关闭后不复活，并验证其它原生指标不受影响。

组件测试覆盖默认开启、提前关闭、行情加载完成、证券/周期切换、中英文切换、历史不足边界、不重建图表和不触碰 Pine；新增图例关闭通知同步、按钮恢复、ref 跨图表重建保留、取消后晚到回调隔离。adapter 测试覆盖图例移除/隐藏事件、其它指标事件隔离及订阅清理。实现沿用 `@luxalgo/vela` 与 `@luxalgo/vela/plugin` 的公开扩展接口，不修改依赖源码。

没有通达信导出数据，初值及零振幅边界按本文约定实现，不声称已与通达信逐值对齐。模拟 fixture 必须明确标识为模拟，不能替代真实行情验收；自动化坐标及生命周期测试也不等同于浏览器视觉验收。
